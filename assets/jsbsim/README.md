# Rascal 110 JSBSim data

This directory contains the flight-dynamics data used by Advanced mode.

`Rascal.xml`, `18x8.xml`, and `Zenoah_G-26A.xml` were adapted without
modification from ArduPilot's `Tools/autotest/aircraft/Rascal` directory on
2026-08-21. ArduPilot identifies the model as derived from FlightGear's Rascal
110 model and describes it as early-stage. Treat it as a useful RC-trainer
baseline, not validated manufacturer test data.

Source: https://github.com/ArduPilot/ardupilot/tree/master/Tools/autotest/aircraft/Rascal
